Guide de Configuration

  1. Allez sur https://fedapay.com
  2. Cliquez sur "S'inscrire" et créez votre compte
  3. Vérifiez votre email
  4. Complétez votre profil (informations entreprise)

  1. Connectez-vous à votre compte FedaPay
  2. Allez dans Paramètres → Clés API
  3. Vous verrez deux ensembles de clés :
    • Sandbox (mode test) : pour tester sans vrais paiements
    • Live (mode production) : pour vrais paiements
  4. Copiez les clés de l'environnement choisi

Mode Sandbox (Test) :

  • Secret Key : sk_sandbox_xxxxxxxxxx
  • Public Key : pk_sandbox_xxxxxxxxxx
  • Environment : sandbox

Mode Live (Production) :

  • Secret Key : sk_live_xxxxxxxxxx
  • Public Key : pk_live_xxxxxxxxxx
  • Environment : live
Important : Commencez toujours avec le mode sandbox pour tester !

Dans certains cas, vous devez activer le mode sandbox sur votre compte FedaPay :

  1. Allez dans Paramètres
  2. Cherchez l'option "Environnement de test" ou "Sandbox"
  3. Activez-le si nécessaire

Note : Sur certains comptes FedaPay, le sandbox est activé automatiquement.
