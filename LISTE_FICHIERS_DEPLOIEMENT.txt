💾 BASE DE DONNÉES
------------------------------------------------------------
Nouvelles colonnes dans la table "users":

• commercial_id (INTEGER)
  → ID du commercial qui a parrainé cet utilisateur
  → NULL si pas de parrainage

• code_commercial (TEXT)
  → Code unique de parrainage (8 caractères)
  → Seulement pour les utilisateurs avec role='commercial'
  → Index unique créé automatiquement

Migration automatique via init_db() dans app.py

============================================================
🔧 COMMANDES PYTHONANYWHERE
------------------------------------------------------------

1. Migration DB (dans Bash console):
   cd prochenous2
   python3 -c "from app import init_db; init_db()"

2. Créer un commercial:
   cd prochenous2
   python3 create_commercial.py

3. Redémarrer l'app:
   Web tab → Reload button
